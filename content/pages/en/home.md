    - question: Do I need to know how to code?
      answer: >-
        You can write and edit content in the CMS without touching code. An agent handles templates and site

    - question: Can I use it without an agent?
      answer: >-
        Yes. The CMS handles posts, page content, images, languages and publishing. An agent or developer is

    - question: Which agents can connect?
      answer: >-
        Use an MCP-capable client that supports the connection method shown in Connect an agent. Client
        capabilities and plans vary; the CMS gives you the endpoint and connection instructions for your site.
    - question: Does Save publish my work?
      answer: >-
        No. Save writes to staging. Publish sends all staged changes to the live branch, so review the pending
        changes before publishing.
    - question: What should I budget for?
      answer: >-

        and limits.
