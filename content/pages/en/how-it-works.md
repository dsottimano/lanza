slots:
  eyebrow: THE HUMAN’S GUIDE
  title: A place for every part of the work.
  intro: >-
    Use a conversation to build the site. Use the CMS to make it yours. Here is the route from a
    rough idea to a published page.
  sections:
    - title: Start with a brief
      paragraphs:
        - text: >-
            Tell your connected agent what the site is for, who it serves and what you want to
            maintain yourself. Bring rough notes, existing copy or material from a voice-note
            conversation. The agent handles the structure and design.
        - text: >-
            Be concrete about what you need to edit later. A workshop listing needs dates and
            descriptions. A landing page needs headlines, images and calls to action. An article
            needs room to write.
      code: |-
        Build a site for my ceramics studio. I need workshops,
        a journal and an about page. Make the text and images
        editable in Lanza. Keep the first version on staging.
    - title: Choose a look or a starting point
      paragraphs:
        - text: >-
            Open Settings → Brand & themes. Brand adjusts shared colours and fonts. Site starters
            adds a Portfolio or Real estate introduction and editable collections, with Editorial,
            Gallery or Nocturne styles scoped to those templates.
        - text: >-
            Review the installation before saving to staging. Existing homepages are preserved;
            conflicting content or routes stop installation. Example copy is English in every
            language and included entries are Ready, so replace or translate them before publishing.
        - text: >-
            Themes imports and exports design bundles. A bundle can overwrite listed files and
            execute build code: use trusted source and inspect the affected files before applying.
            Content and uploaded media are optional export additions.
      items:
        - text: >-
            Starters do not install form processing, bookings, payments, property feeds, maps or
            search.
        - text: Review the staging build, CMS fields and all pending changes before Publish.
    - title: Write an article
      paragraphs:
        - text: >-
            Open Posts and create an entry. Start with a title and body. Formatting stays out of the
            way until you open Format; the slash menu and keyboard shortcuts are available while
            writing.
        - text: >-
            After the entry has a title, edits autosave following a short pause. Check the save
            status before leaving. Focus hides the surrounding navigation when you want fewer
            distractions.
      items:
        - text: Use Details for the excerpt, featured image and publication settings.
        - text: Keep page layout and CSS with your agent; the document is for writing.
    - title: Edit a designed page
      paragraphs:
        - text: >-
            Open a page built with a content template. Its Content panel sits beside the preview.
            Choose a section, or click text in the preview to focus its field.
        - text: >-
            Replace a headline, revise a paragraph or choose another image. Ask your agent when you
            want to add or reorganize structural sections. The fields describe your content, not the
            CSS behind it.
    - title: Give the details some room
      paragraphs:
        - text: >-
            Open Details and choose Expand for a full-width form. Restore brings the writing column
            back without discarding the document.
        - text: >-
            Summary and image controls are separate from Search appearance. Edit the search title,
            description and social image directly. Canonical URL, indexing and structured-data
            options sit under Advanced search settings.
    - title: Work across languages
      paragraphs:
        - text: >-
            Use an entry’s language controls to open or start a linked translation. A new
            translation keeps the structure; it does not pretend the source language’s words are a
            finished translation.
        - text: >-
            Pages and posts can have different public slugs in each language. Owners can edit the
            URL and explicitly Save the change. The old address and its 301 redirect are saved
            together, then go live on Publish.
    - title: Review before publishing
      paragraphs:
        - text: >-
            Save writes to staging. Ready means the entry can appear in the next published build;
            Draft keeps it hidden. Neither status means that saving immediately changes the live
            site.
        - text: >-
            Inspect the pending changes and preview. Publish sends all staged work to the live
            branch, including other pending edits. Cloudflare then builds the updated site. Check
            the live result after the build finishes.
      items:
        - text: Ask agents to explain what changed and where you can edit it.
        - text: Review the entire pending set before publishing.
        - text: If a save reports a conflict, keep your writing and review the latest stored version.
