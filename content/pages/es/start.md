            Necesitas GitHub para el repositorio y Cloudflare para el sitio. Usa cuentas que

            proveedores; dominio y agente tienen costes aparte.
    - title: Crea el sitio
      paragraphs:
        - text: >-
            Abre el proceso de configuración, elige el nombre y sigue los pasos para conectar GitHub
            y Cloudflare. Completa las autorizaciones que soliciten los proveedores.
        - text: >-
            Espera a que termine y comprueba el estado de la construcción y del sitio. Si algo
            falla, resuelve el error concreto antes de dar el sitio por listo.
      link:
        label: Abrir la configuración
        href: https://connect.lanzacms.com/
    - title: Conecta un agente
      paragraphs:
        - text: >-
            En el CMS, abre Connect an agent. Configura un cliente compatible con MCP usando la
            dirección y las instrucciones de credenciales que aparecen allí. La compatibilidad varía
            entre clientes.
        - text: >-
            Introduce las credenciales en la configuración del cliente, no en una conversación
            normal. Pide al agente que lea get_site y describe_site_system antes de empezar.
      link:
        label: Leer la guía para agentes
        href: /es/agents/

      paragraphs:

            navegación; después tú ajustas los textos y las imágenes.
        - text: >-
            Empieza con una página útil. No necesitas una gran operación editorial para tener algo
            que contar.
    - title: Revisa y publica
      paragraphs:
        - text: >-
            Abre el CMS y revisa el contenido y los cambios preparados. Prueba la vista previa en
            móvil y escritorio. Comprueba enlaces, imágenes, versiones de idioma y datos de
            búsqueda.
        - text: >-
