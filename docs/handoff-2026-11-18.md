## 0.1.34 — designed pages enforced, `richtext` template field

Owner approved the release as breaking. A page with a preset is a designed page: it
opens in the template view and its template may not set `"body": true` (`page-body`
in check:site, lanza build and MCP). New `richtext` field (bold, italic, underline,
three sizes, heading/body fonts), sanitized, agent-origin preserved. Implementation
`53ba794`..`c42c9a5`, release/tag `7630267` (`v0.1.34`) on main and staging. See
docs/site-system.md and docs/authoring-templates.md.

Reviews: five Codex code-review passes and two Claude security reviews; 14 findings
fixed, final Codex verdict not release-blocking with no open findings. Known limits:
content committed straight to git is caught only by check:site/lanza build; on sites too
large to scan, MCP `validate_site` returns `complete: false`; a theme install does not
refresh the editor's cached tenant fonts until reload.
