## User decisions, in order of precedence

The product is a system for capturing, developing, owning and eventually publishing
human thought. AI labor should make more room for human thinking, not generate more
content. Original notes, sources and evolution matter; publishing is optional.

The human uses ChatGPT or Claude, ideally voice mode, to think aloud and have the
assistant organize/save thoughts. Lanza is the durable store and human review surface.
An assistant-proposed CMS capture form/voice recorder was the wrong starting point.

D1/R2 free tiers were investigated, but the user then chose a simpler v1: notes in
the person's private Lanza GitHub repo. Do not reopen the private-repo-versus-device
question or start provisioning a database. A separate repo is not required. The
existing public product repo is the exception, not a suitable private notebook.

Crawler visibility is desired later. Read-only Cloudflare analytics permissions
were discussed; raw HTTP request logs are plan-dependent. No OAuth app changes were
verified. Existing onboarding credentials remain temporary; no broker token store.
